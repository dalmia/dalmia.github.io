# Blog posts about Calibrate or AI evals

When adding a blog post here that is about Calibrate or about AI evaluations,
always ask me for the link to the same post on the Calibrate site
(https://calibrate.artpark.ai/blog/...) before you finish.

Then add a line right under the post title, above the first paragraph, in
smaller italics so it reads as a note and not as part of the post:

```html
<p style="font-size: 0.85em; font-style: italic;">This post also appears on the <a href="https://calibrate.artpark.ai/blog/SLUG" target="_blank">Calibrate blog</a>.</p>
```

If I say there is no Calibrate version yet, skip the link and tell me it is
missing. Do not guess the URL.

Examples already doing this:
- blog/2026/08/calibrate-indiafoss.html
- blog/2026/08/testing-your-ai.html
